# 🎁 Amigo Invisible X

Sorteo de amigo invisible en una sola página (`index.html`), sin servidor ni cuentas.

- Añade los participantes y, si quieres, exclusiones (por ejemplo, parejas).
- El sorteo se hace en tu navegador: nadie ve los resultados, ni quien organiza.
- Cada persona recibe un enlace privado con su resultado, un reto divertido y una restricción secreta para el regalo (opcionales).

## Uso

Con GitHub Pages activado (Settings → Pages → rama `main`, carpeta `/ (root)`), la web queda en
`https://xacoy.github.io/amigo-invisible-x/`.

## Nota de privacidad

El resultado de cada persona va codificado (base64) dentro de su enlace. Basta para un grupo de amigos, pero no es cifrado: quien tenga acceso a un enlace puede decodificarlo.
