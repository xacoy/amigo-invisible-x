# 🎁 Amigo Invisible X

Web de AIX (Amigo Invisible eXtraño), sin servidor ni cuentas.

- `index.html`: las instrucciones del ritual, con generador de pistas en rima y de leyendas falsas.
- `sorteo.html`: el sorteo por turnos (participantes, exclusiones, maldiciones y reparto). Todo ocurre en el dispositivo; no se envía nada a ningún sitio.

Con GitHub Pages activado (rama `main`, carpeta `/ (root)`): https://xacoy.github.io/amigo-invisible-x/
